# Story 10 — Docs (doc files to update)

## Goal

Update the **doc files** to the 8-phase process + the new mechanisms
(headcount + pods + the department proposal + the prompts). The **historical /
reference docs** are **NOT** updated (they record the past / the requirements).

## Files to update

- `README.md` — **modify** (the main doc).
- `SETUP.md` — **modify** (the setup / the test instructions).
- `.env.example` — **modify** (the new knobs — from Story 7).
- **Module docstrings** — **modify** (the module-level docstrings for the new
  + updated modules).

## Files NOT updated (historical / reference)

- `AUDIT.md`, `LOG_AUDIT.md`, `RUN_AUDIT.md`, `DEPARTMENT_AUDIT.md` — the
  audit docs (they record the past runs / the audit trail).

  process).
- `MISSION.md` — the mission (generated by the pipeline, not a doc file).

## Detailed changes

### 10.1 `README.md` — the main doc

Update the `README.md` to reflect the 8-phase process + the new mechanisms:

1. **The phase description** — update the phase list from the 6 phases to the
   8 phases:
   `Intake → Mission → Org bootstrap → Plan → Staff → Execute → Evaluate →
   Decide`.
2. **The new mechanisms** — add a section describing:
   - **Headcount caps** — the cap chain (total → department → team → IC) + the
     allotment (Phase 3 / Phase 4) + the finalization pods (Pod A / Pod B).
   - **Pods** — the four kinds (clarification / reporting / headcount /
     execution) + the capped iterations.
   - **The department proposal** — the leader proposes the departments in
     Mission; Org bootstrap creates them.
   - **The prompts** — the prompts are in the `prompts/` location (auditable).
3. **The file structure** — update the file-structure section to the new
   modules:
   - `runtime/plan.py` — Phase 4 (Plan).
   - `runtime/staff.py` — Phase 5 (Staff).
   - `runtime/execute.py` — Phase 6 (Execute).
   - `runtime/dispatch_common.py` — the shared helpers.
   - `prompts/` — the prompts.
4. **The running instructions** — the `run_session.py` / `reset_org.py`
   instructions are unchanged (the CLI is updated in Story 8).

### 10.2 `SETUP.md` — the setup / the test instructions

Update the `SETUP.md` to reflect the new setup (if needed):

1. **The venv** — the venv setup is unchanged (the `SETUP.md` describes how to

   tests/`) are unchanged (the tests are updated in Story 9).

### 10.3 `.env.example` — the new knobs

### 10.4 Module docstrings — the new + updated modules

Update the **module-level docstrings** (the "what this module does"
description) for the new + updated modules:

- **`runtime/plan.py`** — "Phase 4 (Plan): the head workflow (the leader+head
  clarification pod → the department policy → the manager hires → the team/IC
  headcount allotment → the head+manager clarification pods → Pod B)."
- **`runtime/staff.py`** — "Phase 5 (Staff): the manager workflow (the IC
  hires → the task assignment → the manager+ic clarification pods)."
- **`runtime/execute.py`** — "Phase 6 (Execute): the IC execution (the work →
  the self-edits → the execution pods A/B/C → the collaboration pod → the

  Execute phases (the mission digest, the role ensure/fire, the IC invoke, the
  self-edit helpers, the pod triggers, the upward report, the decomposition
  list, the efficiency-panel helpers, the automation)."
- **`runtime/session.py`** — update the docstring to the 8-phase process (the
  8-phase sequence + the cycle loop).
- **`runtime/org.py`** — update the docstring to the department caps + Pod A
  (the headcount allotment).
- **`runtime/pods.py`** — update the docstring to the pod kinds (clarification
  / reporting / headcount / execution) + the capped iterations.
